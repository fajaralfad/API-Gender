# **Gender Classification API**

API ini digunakan untuk melakukan klasifikasi gender pada citra manusia menggunakan model **BEiT** yang telah difine-tune pada dataset **PETA**. Menggunakan FastAPI.

---

## 🙏 **Acknowledgments**

Proyek ini dibangun dengan mengadaptasi dan memanfaatkan sumber-sumber berikut:

- **Model Repository**: `NTQAI/pedestrian_gender_recognition`
- **Base Model**: `microsoft/beit-base-patch16-224`
- **Training Dataset**: **PETA (Pose, Expression, and Attribute)**
- **Model Accuracy**: **91.07%**
